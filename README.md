# Waleed Bin Khalid - Portfolio

A static, production-ready portfolio built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Hugeicons.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static export is generated in `out/` and can be deployed to Vercel, Netlify, or any static host.
